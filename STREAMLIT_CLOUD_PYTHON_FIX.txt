================================================================================
UPDATE (TensorFlow-free Streamlit Cloud)
================================================================================

This project now runs on Streamlit Community Cloud WITHOUT TensorFlow:

  requirements.txt  →  streamlit + numpy + h5py only

Inference uses numpy_inference.py + tokenizer_word_index.json + *.h5 + max_len.pkl.

After changing tokenizer.pkl locally, run:

  python export_tokenizer_json.py

and commit tokenizer_word_index.json.

================================================================================
LEGACY: TensorFlow on Streamlit Cloud with Python 3.14 (still impossible)
================================================================================

Older builds showed:

  "Using Python 3.14.4 environment"

TensorFlow / tensorflow-cpu had NO wheels for Python 3.14 — installs failed.

If you insist on TensorFlow IN THE CLOUD, deploy only on Python 3.11 / 3.12
(delete app → redeploy → Advanced settings) OR use Docker.
